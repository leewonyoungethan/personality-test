# 모험 성격테스트 시리즈

선택지를 고르며 진행하는 **모험형(어드벤처) 선택 게임 스타일** 성격테스트 모음입니다.
순수 HTML/CSS/JS로만 만들어져 있어 빌드 과정 없이 GitHub Pages로 바로 배포할 수 있습니다.

## 구성

- `index.html` — 테스트 목록(홈) 페이지
- `test.html` — 실제로 선택지를 진행하는 공용 테스트 페이지 (`?id=테스트id`로 분기)
- `styles.css` — 전체 디자인
- `js/engine.js` — 모든 테스트가 공유하는 진행/채점/결과 생성 엔진
- `js/home.js` — 홈 화면 카드 렌더링
- `js/tests/*.js` — 테스트별 데이터 (시나리오, 선택지, 결과 유형)

현재 포함된 테스트 5종:

| id | 제목 | 테마 |
|---|---|---|
| fantasy | 잊혀진 마법사의 탑 | 판타지 모험 |
| island | 무인도 생존기 | 서바이벌 |
| space | 은하 최후의 탐사대 | SF |
| mansion | 저주받은 저택의 비밀 | 미스터리 |
| school | 전설의 학교괴담 | 학교괴담 |

## 결과가 100가지인 이유

각 테스트는 3개의 성향 축(A·B·C)을 가지고, 8개의 장면에서 내린 선택에 따라 각 축의 점수가 쌓입니다.
- A축: 4단계
- B축: 5단계
- C축: 5단계

세 축의 조합 → **4 × 5 × 5 = 100가지** 결과 유형이 자동으로 만들어집니다.
결과 제목은 `A축 형용사 + B축 형용사 + C축 명사` 조합으로 생성되고, 설명은 각 축의 해설 문장을 조합해 보여줍니다.

## 새 테스트 추가하는 법

1. `js/tests/` 에 새 파일을 만들고 `fantasy.js`와 같은 구조로 데이터를 작성합니다.
   - `axes`: A(4단계) / B(5단계) / C(5단계) 정의
   - `scenes`: 8개의 장면, 각 장면마다 3개의 선택지 (`points: {A, B, C}`)
   - `closingLines`: 결과 화면 마지막에 보여줄 문장 3개
2. `index.html`, `test.html` 의 `<script>` 목록에 새 파일을 추가합니다.
3. `js/home.js` 의 `order` 배열에 새 테스트 id를 추가합니다.

## 로컬에서 확인하기

별도 빌드 도구 없이, 정적 서버만 띄우면 됩니다.

```bash
npx serve .
```

## 배포 (GitHub Pages)

저장소 Settings → Pages 에서 `main` 브랜치 / root 폴더를 Source로 지정하면 바로 배포됩니다.
